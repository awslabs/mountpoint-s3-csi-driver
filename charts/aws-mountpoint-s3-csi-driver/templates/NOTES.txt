{{- if eq .Values.experimental.mounterMode "daemonset"}}

IMPORTANT: After helm upgrade or rollback, s3-csi-node pods are replaced automatically, which does not affect active mounts.
Mounter pods continue running the previous version (OnDelete strategy) to avoid disrupting active mounts. Until a node's
mounter pod is replaced, its s3-csi-node logs an image mismatch warning and keeps serving mounts.
Node recycling (EKS node group update, Karpenter drift/expiration) completes the upgrade seamlessly.
If node recycling is not feasible, update the node's mounter in place:
kubectl cordon <node-name>
kubectl drain <node-name> --ignore-daemonsets
kubectl delete pod -n {{ .Release.Namespace }} -l app=s3-csi-daemonset-mounter --field-selector spec.nodeName=<node-name>
kubectl uncordon <node-name>
Deleting the mounter pod without draining the node first breaks all active mounts on that node.
